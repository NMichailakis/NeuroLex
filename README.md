# NeuroLex

Εκπαιδευτικό εργαλείο γλωσσικών δεικτών σε μεταγραφές ομιλίας (λεξική ποικιλία TTR/CTTR/MATTR, αντωνυμίες, fillers, μέσο μήκος εκφώνησης). **Δεν διαγιγνώσκει** άνοια ή Alzheimer.

Live: https://neurolex-jet.vercel.app/

Ο κώδικας τρέχει τοπικά στον browser· το κείμενο δεν στέλνεται σε διακομιστή.
